# scenario-03-toggle-complete.md

## User Scenario – Toggle Todo Complete

---

## 1. Scenario Overview

- **Scenario ID**: SCN-003
- **Title**: 사용자는 할 일 완료 상태를 토글한다
- **Primary Actor**: 사용자
- **Goal**: 사용자는 할 일의 완료/미완료 상태를 변경할 수 있다
- **Related AC**: AC-001-06

---

## 2. Preconditions

- TODO 목록 화면이 사용자에게 표시되어 있다
- 목록에 상태를 변경할 할 일이 1개 이상 존재한다

---

## 3. Main Flow (Happy Path)

1. 사용자는 상태를 변경할 할 일을 목록에서 찾는다.
2. 사용자는 해당 할 일에 대해 완료 상태 토글 동작을 수행한다.
3. 시스템은 해당 할 일의 상태가 변경되었음을 사용자에게 보여준다.
4. 사용자는 변경된 완료/미완료 상태를 확인한다.

---

## 4. Alternative / Exception Flows

### A1. 상태를 변경할 할 일이 없는 경우

- 조건: 목록에 할 일이 존재하지 않는다.
- 흐름:
  1. 사용자는 목록이 비어 있음을 인지한다.
  2. 시스템은 변경할 대상이 없음을 사용자에게 인지시킨다.

### E1. 상태 변경 대상이 더 이상 존재하지 않는 경우

- 조건: 사용자가 토글 동작을 수행하려는 시점에 해당 할 일이 존재하지 않는다.
- 결과: 시스템은 상태 변경이 수행되지 않았음을 사용자에게 인지시킨다.

---

## 5. Postconditions

- 정상적인 경우:
  - 선택한 할 일의 완료 상태가 변경되어 있다.
- 실패한 경우:
  - 해당 할 일의 상태는 변경되지 않은 상태다.

---

## 6. Notes

- 완료 상태의 시각적 표현 방식(아이콘/스타일 등)은 본 시나리오에서 다루지 않는다.
- 완료 항목 필터링/정렬은 본 시나리오에서 다루지 않는다.
