# scenario-01-create-todo.md

## User Scenario – Create Todo

---

## 1. Scenario Overview

- **Scenario ID**: SCN-001
- **Title**: 사용자는 할 일을 추가한다
- **Primary Actor**: 사용자
- **Goal**: 사용자는 새로운 할 일을 목록에 추가할 수 있다

---

## 2. Preconditions

- 사용자는 TODO 서비스에 접근할 수 있는 상태다
- TODO 목록 화면이 사용자에게 표시되어 있다

---

## 3. Main Flow (Happy Path)

1. 사용자는 할 일 입력 영역을 인지한다.
2. 사용자는 입력 영역에 할 일 내용을 입력한다.
3. 사용자는 할 일을 추가하기 위한 동작(예: 버튼 클릭)을 수행한다.
4. 시스템은 입력된 할 일을 TODO 목록에 표시한다.
5. 사용자는 추가된 할 일을 목록에서 확인한다.

---

## 4. Alternative / Exception Flows

### A1. 입력 없이 추가를 시도하는 경우

- 조건: 사용자가 할 일 내용을 입력하지 않는다.
- 흐름:
  1. 사용자는 할 일 추가 동작을 수행한다.
  2. 시스템은 할 일이 추가되지 않았음을 사용자에게 인지시킨다.

### E1. 입력이 유효하지 않은 경우

- 조건: 사용자가 허용되지 않은 형식의 입력을 한다.
- 결과: 시스템은 할 일이 추가되지 않았음을 사용자에게 인지시킨다.

---

## 5. Postconditions

- 유효한 입력이 제공된 경우:
  - TODO 목록에는 새로운 할 일이 포함되어 있다.
- 유효하지 않은 입력이 제공된 경우:
  - TODO 목록은 변경되지 않은 상태다.

---

## 6. Notes

- 할 일의 수정, 삭제는 본 시나리오에서 다루지 않는다.
