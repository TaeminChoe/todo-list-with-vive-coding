## User Scenario Template

---

## 1. Scenario Overview

- **Scenario ID**: SCN-XXX
- **Title**: 사용자 관점에서 표현한 시나리오 제목
- **Primary Actor**: (예: 사용자, 관리자 등)
- **Goal**: 이 시나리오를 통해 사용자가 달성하려는 목적
- **Related AC**: AC-XXX (해당하는 Acceptance Criteria)

---

## 2. Preconditions

- 시나리오가 시작되기 전에 충족되어야 하는 조건
- (예: 로그인 상태, 초기 데이터 없음 등)

---

## 3. Main Flow (Happy Path)

1. 사용자는 … 한다.
2. 시스템은 … 을 보여준다.
3. 사용자는 … 을 선택한다.
4. 시스템은 … 상태가 된다.

※ 구현 방식이 아니라 **관찰 가능한 행동/결과**만 작성한다.

---

## 4. Alternative / Exception Flows

### A1. 대안 흐름 1
- 조건: …
- 흐름:
  1. 사용자는 …
  2. 시스템은 …

### E1. 예외 흐름 1
- 조건: …
- 결과: 사용자에게 … 이 인지된다.

## 5. Postconditions

- 시나리오 종료 후 시스템이 도달해야 하는 상태
- 사용자가 인지할 수 있는 결과만 기술한다.
