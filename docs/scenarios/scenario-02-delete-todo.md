# scenario-02-delete-todo.md

## User Scenario – Delete Todo

---

## 1. Scenario Overview

- **Scenario ID**: SC-02
- **Title**: 사용자는 할 일을 삭제한다
- **Primary Actor**: 사용자
- **Goal**: 사용자는 기존 할 일을 목록에서 제거할 수 있다

---

## 2. Preconditions

- TODO 목록 화면이 사용자에게 표시되어 있다
- 목록에 삭제할 할 일이 1개 이상 존재한다

---

## 3. Main Flow (Happy Path)

1. 사용자는 삭제할 할 일을 목록에서 찾는다.
2. 사용자는 해당 할 일에 대한 삭제 동작을 수행한다.
3. 시스템은 해당 할 일이 목록에서 제거되었음을 사용자에게 보여준다.
4. 사용자는 목록에서 해당 할 일이 사라진 것을 확인한다.

---

## 4. Alternative / Exception Flows

### A1. 삭제할 할 일이 없는 경우

- 조건: 목록에 할 일이 존재하지 않는다.
- 흐름:
  1. 사용자는 목록이 비어 있음을 인지한다.
  2. 시스템은 삭제할 대상이 없음을 사용자에게 인지시킨다.

### E1. 삭제 대상이 더 이상 존재하지 않는 경우

- 조건: 사용자가 삭제 동작을 수행하려는 시점에 해당 할 일이 존재하지 않는다.
- 결과: 시스템은 삭제가 수행되지 않았음을 사용자에게 인지시킨다.

---

## 5. Postconditions

- 정상적인 경우:
  - 선택한 할 일은 목록에서 제거되어 있다.
- 실패한 경우:
  - 목록은 변경되지 않은 상태다.

---

## 6. Notes

- 삭제 전에 확인(확인 창 등) 여부는 본 시나리오에서 다루지 않는다.
- 복구(Undo) 기능은 본 시나리오에서 다루지 않는다.
